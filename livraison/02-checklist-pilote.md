# Liste de contrôle du pilote sur données réelles

Pilote : une ferme, saisie manuelle uniquement (téléphone `/terrain` et écrans du bureau), registres papier
tenus en parallèle. Aucun capteur ni équipement raccordé pendant le pilote.

## Avant le pilote

| Fait | Étape | Responsable |
|---|---|---|
| ☐ | Choisir la ferme pilote et son responsable sur site | Client |
| ☐ | Répondre aux décisions ([01-decisions-client.md](01-decisions-client.md)) | Client |
| ☐ | Remplir les trois modèles (`modeles/`) : structure, utilisateurs, lots en cours | Client |
| ☐ | Signer la convention de pilote | Client et BVU Tech |
| ☐ | Déposer la déclaration CNDP (loi 09-08) | BVU Tech / Client — selon le responsable du traitement, à confirmer avec le juriste |
| ☐ | Compléter les mentions légales du site (ICE, RC, adresse, hébergeur…) | BVU Tech |
| ☐ | Livrer la version pilote : installation propre, comptes sécurisés, structure de vos élevages | BVU Tech |
| ☐ | Configurer l'envoi des alertes par e-mail | BVU Tech |
| ☐ | Mettre en place la sauvegarde quotidienne, la copie hors du serveur, et faire une restauration d'essai | BVU Tech |
| ☐ | Créer les comptes ; chaque personne change son mot de passe ; connexion en deux étapes pour Administrateur, Responsable qualité et Direction | BVU Tech et Client |
| ☐ | Former chaque rôle sur l'instance de démonstration | BVU Tech |
| ☐ | Tester l'application terrain avec les éleveurs (langue, lisibilité, téléphones) | Client et BVU Tech |
| ☐ | Vérifier les téléphones : navigateur à jour, réseau au moins une fois par jour | Client |

## Pendant le pilote

| Fait | Étape | Responsable |
|---|---|---|
| ☐ | Saisir chaque jour : mortalité, aliment, eau, pesées | Client |
| ☐ | Continuer les registres papier | Client |
| ☐ | Arbitrer les saisies contradictoires (sous 30 jours) | Client (responsable) |
| ☐ | Prendre en compte les alertes et décrire l'action menée | Client |
| ☐ | Comparer chaque semaine la plateforme et le papier ; expliquer chaque écart | Client et BVU Tech |
| ☐ | Contrôler chaque semaine Administration → Exploitation et les sauvegardes | BVU Tech |
| ☐ | Faire une restauration d'essai chaque mois | BVU Tech |
| ☐ | Tenir le registre des incidents et des demandes | BVU Tech |

## Après le pilote

| Fait | Étape | Responsable |
|---|---|---|
| ☐ | Rédiger le bilan : critères de réussite atteints ou non, écarts, incidents | BVU Tech |
| ☐ | Remettre l'export des données du pilote (fichiers CSV) | BVU Tech |
| ☐ | Décider de la suite (go / no-go), par écrit et signé | Client et BVU Tech |
| ☐ | Si go : planifier les autres fermes | Client et BVU Tech |
| ☐ | Pour les capteurs et machines : relevé du site, liste d'équipement, devis, essais au banc (FAT), installation, essais sur site (SAT) | Client et BVU Tech |
